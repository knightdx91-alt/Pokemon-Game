TierMaker Grabber
Save every card from a TierMaker page

What it does

Runs on the TierMaker page in your browser (the only place past Cloudflare), pulls every card image at full resolution, and downloads them as one self-contained tiermaker-cards.html gallery to your phone. From Downloads you can open it, or use the Share ▸ Drive to save it to Google Drive — no app needed.

Install on Android Chrome

  1. Copy the bookmarklet code below (tap Copy code).
  2. Bookmark any page (tap ☆ in the menu).
  3. Open Bookmarks, tap Edit on that bookmark.
  4. Set Name to Grab Cards and paste the copied code into the URL field. Save.
  5. Go to your TierMaker page (e.g. the Mistborn one). In the address bar type Grab Cards and tap the bookmark suggestion.
  6. Wait for the status bar at the bottom — it saves tiermaker-cards.html to Downloads.

Chrome blocks typing javascript: directly in the address bar, which is why it has to live in a bookmark. Typing the bookmark's name and tapping it runs the code on whatever page you're currently viewing.
