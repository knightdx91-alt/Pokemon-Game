# RPG Maker — engine binaries & RTP

The RPG Maker **VX Ace** (and XP) engine binaries, character Generator, and RTP
asset library. Migrated here from the old `rpgmaker-temp` branch so nothing lives
on a side branch.

- `extracted/` — unzipped tree: `vxace-binaries/` (`RPGVXAce.exe`, `RGSS301.dll`,
  Steam DLLs), `vxace-generator-rtp/` (Generator faces/parts + RTP).
- `rpgmaker-binaries.zip`, `rpgmaker-needed.zip`, `rpgmaker-xp.zip` — the original
  archives (same content as `extracted/`, kept as-is).

Not to be confused with the top-level `RPG_MAKER/` directory, which is a separate
game project, not the engine install.
